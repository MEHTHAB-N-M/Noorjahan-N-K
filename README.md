## 🛠️ Software & Technical Toolkit

Noorjahan combines rigorous spatial drafting software with photorealistic rendering pipelines:

```
Spatial Design & Drafting
 ├── AutoCAD          ── Precision 2D plans, sections, and elevation layouts
 ├── SketchUp         ── Rapid spatial volumetrics and conceptual massing
 ├── 3ds Max          ── Advanced geometry and realistic asset modeling
 ├── Coohom           ── Fast interior rendering, material mapping & panoramas
 └── Joy Plan         ── Efficient on-site space planning and layout generation

Visualization & Post-Production
 ├── Enscape          ── Real-time ray-traced lighting and atmospheric scenes
 └── Adobe Photoshop  ── Texture correction, moodboards, and presentation sheets

Tactile Model Crafting
 ├── Clay Modeling    ── Organic form studies and sculptural exploration
 └── Thermocol Craft  ── Structural scale mockups and site massing
```

## 💻 Website Tech Stack

The web portfolio is engineered for optimal performance, smooth responsiveness, and lightning-fast load times:

* **HTML5:** Clean semantic structure with accessible document outlining.
* **Tailwind CSS:** Modern utility-first styling with custom stone color palettes (`bg-stone-50`, `text-stone-900`, `bg-stone-400`).
* **Font Awesome 6:** Vector iconography for software, education, and contact widgets.
* **Google Fonts (Outfit):** Geometric neo-grotesque sans-serif offering architectural clarity.
* **Netlify Deployment:** Continuous delivery, CDN-accelerated asset hosting, and automatic HTTPS.

## 🚀 Running Locally

To preview or develop the portfolio website on your local machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/MEHTHAB-N-M/Noorjahan-N-K.git
   cd Noorjahan-N-K
   ```

2. **Open in browser:**
   - Simply double-click `index.html` to launch it in any modern browser.
   - Or start a lightweight local development server:
     ```bash
     # Using Python
     python -m http.server 8000
     ```
     Navigate to `http://localhost:8000` in your browser.
